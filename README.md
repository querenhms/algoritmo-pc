## Sobre o Repositório

Este repositório tem como objetivo armazenar e organizar as atividades práticas desenvolvidas durante a disciplina de Algoritmos e Pensamento Computacional. Os exercícios e projetos são desenvolvidos utilizando a linguagem C, com foco no desenvolvimento do raciocínio lógico, resolução de problemas e aplicação dos conceitos de programação.
